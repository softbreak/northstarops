# Changes Requested Sonrası Düzeltme Yapma

Reviewer Pull Request üzerinde değişiklik talep ettiğinde yeni bir PR açma.

## Yapman gereken

1. PR üzerindeki review notlarını oku.
2. Aynı local branch üzerinde gerekli düzeltmeleri yap.
3. Testleri tekrar çalıştır.
4. Değişiklikleri commit et.
5. Aynı branch'e push et.

GitHub mevcut Pull Request'i otomatik olarak günceller.

## Temel kural

**Aynı Issue → aynı branch → aynı Pull Request.**

Yeni PR açmak lifecycle bağlantısını bozar ve kabul edilmeyebilir.

## Review thread'leri

Reviewer'ın açtığı konuşmaları yalnızca gerçekten çözüldükten sonra resolve et. `main` branch ruleset'i çözülmemiş review conversation'ları varken merge'e izin vermez.

## Sonraki adım

Güncelleme tamamlandığında reviewer aynı PR'ı yeniden değerlendirir. Onay gelirse [approval sonrası rehberine](after-approval.md) geç.
